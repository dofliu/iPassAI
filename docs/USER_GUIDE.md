## 1. 隱私與離線原則

所有練習紀錄、模考成績、收藏、筆記與推播設定，**完全儲存在您目前使用的瀏覽器或 Android 裝置端**（`localStorage`）。無需註冊或登入，沒有任何個資上傳。

這也代表：**換裝置或清除瀏覽器資料時紀錄不會跟著走**，請善用第 9 節的 JSON 備份功能。

## 2. 五大功能面板

透過左側「學習軌道」側邊欄，或手機底部的快捷導航列切換：

| 面板 | 主要用途 |
| :--- | :--- |
| **學習首頁** | 連續學習天數、今日完成率、考期倒數、今日複習計畫與考科索引。 |
| **即時練習** | 依考科、主題、難度抽題，作答後立即揭示正解與易錯解析。 |
| **模擬測驗** | 依官方題量與時限進行全真倒數模考，交卷後產出能力診斷成績單。 |
| **錯題複盤** | 彙整歷史錯題與弱點主題排行，一鍵啟動「錯題專屬測驗」。 |
| **收藏與筆記** | 全文檢索、篩選、個人筆記維護與星號收藏管理，以及資料備份還原。 |

## 3. 即時練習

適合日常碎片化學習與概念建立：

1. **設定篩選條件** — 選擇級別（初級／中級／專業認證）與考科，可再指定主題與抽題題數（5／10／20／25 題）。
2. **作答與即時反饋** — 點選答案後送出，系統即時標示正確選項並提供：
   - 💡 **深度核心解析**：解題依據與觀念說明。
   - ⚠️ **易錯提醒**：點出最容易誤選的干擾項為何錯。
   - 🔗 **來源連結**：可查閱對應的官方考綱或考試資訊。
3. **逐題筆記與收藏** — 每題可點「收藏此題」標記星號，並在「我的筆記」即時輸入解題口訣，自動儲存。

## 4. 全真標準模擬考試

專為正式應試節奏打造的高仿真考場體驗。**各考科的完整題量、時限與及格標準請見 [專案規劃書的考科規格矩陣](PROJECT_PLAN.md#-考科規格矩陣)**，選定考科後模考設定卡也會直接顯示該科規格。

### 操作流程

1. **切換模考模式**
   - 🏆 **全真標準模考**：套用官方完整題量與時限。
   - ⏱️ **自訂題數模考**：彈性題數與時間，適合短時間練手。
2. **題目標記 (Flag for Review)** — 遇到不確定的題目點「標記此題」，答題卡即刻標註黃色星號。
3. **答題卡矩陣導覽** — 頂部清楚區分已答（深藍）、未答（白色）與標記（黃色），點任意題號即可跳題。
4. **最後 5 分鐘警示** — 倒數剩 5 分鐘時計時器自動轉為警示色。
5. **交卷防呆** — 若仍有漏答，交卷時會跳出確認對話框提示未答題數。
6. **能力診斷成績單**
   - **及格判定**：👑 考試合格 (PASS) 或 ⚠️ 未達及格標準 (FAIL)。
   - **分項主題掌握度診斷條**：逐一列出各主題得分率（👑 ≥80% 精熟／⚡ 60–79% 尚可／⚠️ <60% 待加強）。
   - **一鍵錯題重測**：針對本次答錯題目立即啟動專屬衝刺。
   - **逐題覆盤**：可切換「全部試題／只看錯題／只看標記題」檢閱作答與正解解析。

## 5. 隨堂快問快答與手機推播抽考

利用零碎時間加深關鍵題型印象：

### 隨堂快問快答 (Pop Quiz)

點擊頂部的「⚡ **隨堂抽考**」按鈕，系統依您設定的偏好抽一題進行快問快答。作答後直接在彈窗內顯示正解與解析，並自動計入學習紀錄與錯題庫。

### 手機定時推播設定（Android 原生支援）

點擊頂部的「🔔 **推播設定**」按鈕：

- **啟用開關** — 開啟或關閉本機定時測驗推播。
- **推播頻率** — 每 1 小時／每 2 小時／每 4 小時，或**每日 3 次定時**（09:00、14:00、20:00）。
- **抽考題庫偏好**
  - 🎯 優先抽考歷史錯題與弱點（無錯題時自動隨機出題）
  - 📚 全題庫隨機抽取
  - 🤖 iPAS AI 初級專屬 ／ ⚡ iPAS AI 中級專屬
  - 🌍 國際英語檢定專屬
  - 🧠 Claude 認證 CCAR-F 專屬
- **即時測試** — 點「發送測試通知」，2 秒後驗證通知是否正常送達；點擊通知可直接喚起 App 並開啟作答視窗。

> Android 13 以上版本需要授權通知權限才能在背景接收抽考題，面板會在未授權時顯示「授予權限」按鈕。

## 6. 錯題複盤與弱點診斷

- **弱點主題排行榜** — 系統統計最近 14 天各主題的錯誤率，推薦答錯率最高的前三大弱點。點任一主題即可針對該弱點抽題特訓。
- **錯題專屬測驗** — 純粹從歷史答錯的題目中抽題組卷，直到完全弄懂為止。
- **作答歷史軌跡** — 時間序列作答清單，記錄每筆練習的成果與日期。

## 7. Cambridge B2 First 聽讀測驗

在英文科將「英文模式」切換為 **Cambridge B2 First** 後啟用：

1. **Reading & Use of English (Part 1–7)** — 多選克漏字、開放式克漏字、單字衍生轉換、關鍵字句型改寫、長篇閱讀、段落填空與多方配對。長篇材料以專屬紙本閱讀框呈現。
2. **Listening (Part 1–4)** — 短對話、單句聽寫、多方觀點配對與長篇訪談。
   - **原創語音朗讀**：內建英國口音（en-GB）語音引擎，支援標準速度（0.88×）與慢速精聽（0.68×）。
   - **逐字稿檢閱**：查看解析時可展開完整音訊逐字稿對照學習。

## 8. Claude 認證 CCAR-F 考科

針對 **Claude Certified Architect – Foundations** 提供 123 題原創仿真題，涵蓋官方五大領域。在級別選單選擇「**專業認證**」即可進入。

| 領域 | 官方權重 | 涵蓋重點 |
| :--- | :---: | :--- |
| 代理架構與協作編排 | 27% | Agent SDK／Tool Runner／Managed Agents 的取捨、協調者–子代理模式、hooks、多代理拓撲 |
| Claude Code 設定與工作流 | 20% | CLAUDE.md 階層、斜線指令、hooks、權限與 MCP 設定範圍、CI 無頭執行 |
| 提示工程與結構化輸出 | 20% | 結構化輸出、strict 工具、自適應思考與 effort、引用、快取友善的提示編排 |
| 工具設計與 MCP 整合 | 18% | MCP 三種原語、工具描述與錯誤處理、工具搜尋、伺服器端工具 |
| 情境管理與可靠性 | 15% | 提示快取、情境編輯與壓縮、批次處理、錯誤處理與重試 |

**全真模考為 60 題 / 120 分鐘 / 720 分（1000 分制）及格**，且會**依上述權重自動配額抽題**，而非單純隨機抽取——每份模考的領域配比都與正式考試一致。由於題庫（123 題）遠多於單次模考題量（60 題），重複應考會抽到明顯不同的考卷。

> ℹ️ 本考科題目為**依官方公開考綱自編的原創題**，技術內容對照 Anthropic 官方文件確認，**非官方考古題**。詳見 [題庫研究依據](RESEARCH_SOURCES.md)。

## 9. 考期倒數、筆記收藏與資料備份

### 考期倒數與每日目標

在學習首頁設定「目標考期」，系統依剩餘題庫與 1.2 輪複習標準，自動計算「每日建議題量」與「每週學習目標」，並以環形進度條呈現今日完成率。

### 題庫檢索

在「收藏與筆記」面板支援關鍵字全文檢索（題幹、選項、考科、主題），並可依級別、考科、測驗模式、主題標籤、難度篩選，或切換「只看收藏」。

### 私密資料備份

- **匯出備份** — 將所有收藏與逐題筆記下載為標準 `.json` 檔。
- **匯入還原** — 選取備份檔後，系統先列出有效題數，再讓您選擇：
  - **安全合併 (Merge)**：保留現有筆記並合併備份內容（同題以現有內容優先）。
  - **完整還原 (Overwrite)**：以備份檔完全覆蓋目前資料。

> 建議在換手機、清除瀏覽器資料或重裝 App 前先匯出備份。
